ZEMEN - START HERE
Detection integrity and Ethiopian calendar context for OpenSearch / Wazuh

1. GET THE PROGRAM
   Build from source (needs Go 1.22+):
     git clone https://github.com/Yohannes-Negero/zemen.git
     cd zemen
     go build -o zemen.exe ./cmd/zemen
   Or download zemen-windows-amd64.exe from the Releases page and rename it
   to zemen.exe.

2. START OPENSEARCH
   Docker Desktop with your container running. Wait about a minute.

3. OPEN POWERSHELL in the folder that has zemen.exe
   (click the address bar, type powershell, press Enter).

4. SET YOUR CONNECTION (lasts only while this window is open)
   $env:ZEMEN_OPENSEARCH_URL = "http://localhost:9200"
   $env:ZEMEN_OPENSEARCH_USERNAME = "admin"
   $env:ZEMEN_OPENSEARCH_PASSWORD = "your real password"

5. RUN IN ORDER
   .\zemen.exe init
   .\zemen.exe doctor
   .\zemen.exe init-indices
   .\zemen.exe sync
   .\zemen.exe status
   doctor should end with "All checks passed."

6. START THE DASHBOARD AND SCHEDULER
   .\zemen.exe run
   Leave the window open and visit http://127.0.0.1:8080.
   For other commands, open a second PowerShell window and repeat step 4.

7. WORK THROUGH THE RUNBOOK (docs\Zemen_Live_Test_Runbook.docx)
   Part A first (read-only), then Part B, then Part C
   (real events in your lab, so lab only).
