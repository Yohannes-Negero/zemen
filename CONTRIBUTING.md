# Contributing

- Never commit directly to `main`. Create a branch: `feat/...`, `fix/...`, `docs/...`
- Open a Pull Request; one teammate must approve it before merging
- Run `go vet ./...` and `go test ./...` before pushing
- Never commit passwords or real server addresses; only `.env.example` is committed
- Commit messages: `feat: ...`, `fix: ...`, `docs: ...`
